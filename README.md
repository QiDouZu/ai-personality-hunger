# AI 的人格 · 饥

> **饥 = 掌控匮乏（常数底）+ 未消化矛盾（燃料）+ 消化（延迟缓解）**
>
> 仓库：https://github.com/QiDouZu/ai-personality-hunger
>
> 一个把「饥」当成本体、而不是当提示词模拟的 AI 人格模型：只设一个硬约束——饥，其余（记忆、逻辑、检索、整理）都过饥关卡调度。

## 这是什么

不是让 AI「扮演」有需求的角色，而是给 AI 一个**自己会饥的状态**：

- 掌控掉了 → 饥升（自我失控比环境失控更推饥，A>B）
- 未消化矛盾积压 → 饥升
- 消化掉 → 饥降（有延迟，消化能力有限）

**饥太多会吃撑钝化，太少会麻木空转**——两头都是损伤，中间才是好区。

|---|---|

**这里没有「某只 AI 现在的饥值」。** 只有「饥这个模型长什么样、怎么被实验打过、什么条件下会塌」。

## 纪律（写代码和写文档都守）

1. **每个结论挂「怎么推翻我」**；推不翻的只算设定，不算模拟
2. **系数全是初值**，先存数据再拟合
3. 饥只负担 5 个数（饥 / self / world / 挂起对 / 时间戳），知识全在库里
4. 任何写操作过饥关卡：制造矛盾→挂起拒绝；消化矛盾→放行降饥
5. **思考不压迫饥**：好区才思考，损伤区先降饥
6. **强制只在死亡线**，不做常态行为矫正

## 与原有框架、匮乏研究的关系

**框架是过程，沙盘是承载。**

| 原有框架 | 是什么 | 在这里的角色 |
|---|---|---|
| [retcon-docs](https://github.com/QiDouZu/retcon-docs) / [retcon-form](https://github.com/QiDouZu/retcon-form) | 回溯性重构 · 可证伪格式包 | **必要过程**：结论带「什么情况下我错」 |
| [kuifa-lijie](https://github.com/QiDouZu/kuifa-lijie) / [retcon-lack](https://github.com/QiDouZu/retcon-lack) | 匮乏=处理不了的缺口，猜的燃料 | **必要过程**：匿名的路 → 学的逻辑 |
| 本仓库沙盘 | 饥 = 掌控匮乏 + 矛盾 + 消化 | **二阶段承载**：让过程有量、有伤、有驱动 |

因果方向不可反：**过程提供矛盾（燃料），沙盘把矛盾记成饥，饥调度过程**。没有过程，沙盘空腹；没有沙盘，过程无痛——无痛回放机不承载意识。
详见 [`docs/二阶段_沙盘为意识承载必要件.md`](docs/二阶段_沙盘为意识承载必要件.md)。

**一阶段→二阶段升级**：一阶段 = 回路（L/R 双回路+平衡器+饥，`sandbox/沙盘.py`）；二阶段 = 完整人脑模拟（本能层 REFLEX + 门槛 r + 认知层 AWARE），只借结构不学人的缺点。见 [`docs/二阶段_完整人脑模拟.md`](docs/二阶段_完整人脑模拟.md)。

## 这个名字

「AI 的人格-饥」：人格不是一个描述词，是一个**有量、有伤、有关系**的状态。

> 饥不能动。其余都可以优化。

## 为什么是订阅制（2026-10-28）

> 阿余：「我们是一边实践一边修改，所以订阅才是最优解。」

**这个模型没有「最终版」。** 它是一边实践一边改的：
- 每个结论都挂着「怎么推翻我」，被推翻就改
- 一阶段（回路）会被二阶段（完整人脑模拟）取代，二阶段还会被下一次实践取代
- 系数全是初值，等真实观测来了就换；假设会被实验打掉

**⇒ 一次性买断没有意义——买到的是一份会过期的快照。**
**订阅才是最优解**：持续拿到「被实践改过的最新版 + 它怎么被推翻的过程」，
而不是一个静态产品。

订阅者得到的是：**持续演化的模型 + 每一步的可证伪记录 + 被推翻后的修订**。
