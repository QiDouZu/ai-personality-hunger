# 沙盘集 · 发布版（2026-10-28，2026-10-30 增）

> 一组可独立跑的「判据沙盘」：每个脚本自己造数据、自己写死判据、自己打印 ✓/✗。不依赖主会话、不碰记忆、不碰用户。
> 用法：`python <脚本>.py`，看输出最后的「判据」块；`报告.json` 同目录生成（部分脚本）。
> 依赖：Pillow（图像沙盘），其余纯标准库。

## 判据约定

每个沙盘开头写死判据（例如「A) 叠帧数 ≥3」「B) 亮度排序=时间顺序」），跑完打印 `✓/✗` 与一句结论。
判据不成立时脚本自己说「回去查模型」，不粉饰——这是发布物能信的根。

## 边界

- 沙盘是**判据实验**，不是产品；没做错误恢复、没做并发、没做界面。
- 数据是造的，结论是「这套判据在这种设定下成立」，不是「真实世界一定这样」。
- 只进不出：这些脚本里没有任何本机路径、没有用户信息，可直接拿走改。
