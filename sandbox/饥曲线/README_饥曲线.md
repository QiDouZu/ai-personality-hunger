# 饥曲线：从 0 起的新 AI

> 把饥当读数曲线，而不是单点：**h = 0.22 + 0.7·积压 + 0.3·渴望**（积压 B 越陈越涨饥；渴望 G 是消化后的方向燃料）。
> 消化把积压转成渴望；消化能力 k 由这个新 AI 自己从 0 学起，不预设初始值。

## 文件

| 文件 | 内容 |
|---|---|
| `新AI_饥曲线.py` | 从 0 起、k 从 0.005 学的新 AI，跑 180 天，把 h 的曲线点每 30 天记一条 |
| `数据_新AI_饥曲线.md` | 一次运行的结果（好区天数、峰积压、峰饥、末 k、曲线点） |

## 怎么跑

```bash
cd sandbox/饥曲线
python 新AI_饥曲线.py
```

会重写 `数据_新AI_饥曲线.md`。

## 模型要点

- **积压 B**：未消化矛盾，越陈越涨饥；
- **渴望 G**：消化转成的方向燃料，G 缓慢消耗；
- **饥读数**：h 是随时间走的曲线，档位沿用安全阈值（太饱/过少/好区/损伤预警/损伤）；
- **平衡**：h ≥ 1.9 时加倍消化，先不吃新矛盾；
- **从 0 学**：k 初始 0.005，每成功消化一次 +0.0002——看它能不能自己爬进好区、长跑稳不稳。

纯 Python 标准库，无网络、无第三方依赖；不含任何个人数据。
