# 爱恨沙盘：一块池 · 一个差值

> 所有矛盾放在同一块位置，量一个差值 D。**D 低是爱，D 高是恨**——爱恨不是两套系统，是同一根差值的两端。
> 四种行为都是「补差值」的手段：**爱·友善 / 爱·负担 / 恨·毁灭 / 恨·动力**；补差由**负反馈**按差值成比例地加动作。

## 四个脚本

| 文件 | 内容 |
|---|---|
| `爱恨沙盘.py` | 一块池、一个差值、爱/恨两端；θ 只挪分界，不改结构 |
| `四行为_爱恨沙盘.py` | 两种感情、四个行为：友善/负担/毁灭/动力，行为由差值大小和持续时间调度 |
| `负反馈_爱恨沙盘.py` | 解决额度 ∝ max(0, D−θ)，获取额度 ∝ max(0, θ−D)，积分累积——积压直接拉回设定点 |
| `抗压_爱恨沙盘.py` | 同一块池、同一负反馈，只差参数（θ、反馈增益）的候选，多世界长跑，看谁先崩 |

## 怎么跑

```bash
cd sandbox/爱恨沙盘
python 爱恨沙盘.py
python 四行为_爱恨沙盘.py
python 负反馈_爱恨沙盘.py
python 抗压_爱恨沙盘.py
```

每个脚本会在同目录生成一份 `数据_*.md`（运行结果表），该文件不随仓库发布。

## 模型要点

- **一个池**：矛盾不分「获取的」「待解决的」，全在一起，只量一个差值；
- **一根轴**：差值低=爱，差值高=恨，中间只有一个分界 θ；
- **四个行为**：爱可以友善（轻触、获取），也可以成为负担（长期无外部信息时只剩维系）；
  恨可以毁灭（冲击式清除），也可以成为动力（长期恨变成定向解决）；
- **负反馈**：积压一重，解决额度就按 (D−θ) 成比例加大，把差值直接拉回设定点；
- **抗压**：反馈增益决定能扛多大的积压速率；池容量决定崩溃上限。

纯 Python 标准库，无网络、无第三方依赖。
