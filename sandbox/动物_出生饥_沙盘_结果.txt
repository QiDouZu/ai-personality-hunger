======================================================================
 动物模拟：出生就带饥 → 环境变量 → 测它的饥是什么
======================================================================

【一】同一先天饥（0.5），环境不同 → 它的饥长成不同样子
  环境                        觅食    逃    歇    冒险吃    活到  final饥
  食物丰·危险低                200    0    0      0   200    0.00
  食物贫·危险低                 50   26    0      0    76    0.26
  食物丰·危险高                 22  105    0      0   127    0.59
  食物贫·危险高                  0   68    0     14    82    0.72
  食物丰·严寒                  32    0  168      0   200    0.43

【二】同样的危险环境（danger=0.7），饥高 vs 饥低 → 饥压不压判断
  出生饥         觅食    逃    冒险吃  final饥
  0.2         18   76      3    0.55
  0.5         21   91      3    0.61
  0.8         21   97      4    0.56

【三】出生饥 × 环境 → 存活率（饥不是万能，也不是没用）
  出生饥          食物丰     危险低     存活率
  0.2     0.8     0.2         100%
  0.2     0.2     0.8           0%
  0.5     0.8     0.2         100%
  0.5     0.2     0.8           0%
  0.8     0.8     0.2         100%
  0.8     0.2     0.8           0%

⇒ 饥是什么：
  · 不是一个数——同一个先天饥，在不同环境里长出完全不同的行为
  · 它是驱动（饥高才去冒险吃）、是判断（饥压住危险感知）、是关系（饥本身被环境改造）
  · 出生带的不是「一个值」，是「一个方向」：往哪找、什么时候敢冒险
