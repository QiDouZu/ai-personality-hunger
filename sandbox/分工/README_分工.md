# 分工：新 AI 从 0 学「怎么切能力」

> 认知不是调一个"消化快慢"的旋钮，而是**分工**：同一份能力切成三份——
> **追求渴望**（针对性地找有方向的新矛盾）· **释放积压**（消化积压，转成方向燃料）· **停止**（空着，防踩爆也防过饱）。
> 停止不是不干活，也是分工的一份。

## 文件

| 文件 | 内容 |
|---|---|
| `新AI_分工.py` | 从 0 起的新 AI：stop 初始 0.05，进损伤预警学会多停、太饱学会少停；跑 180 天 |
| `数据_新AI_分工.md` | 一次运行结果（好区天、峰积压、峰饥、期末 stop、三份占比、曲线点） |

## 怎么跑

```bash
cd sandbox/分工
python 新AI_分工.py
```

会重写 `数据_新AI_分工.md`。

## 模型要点

- **积压 B**：未消化矛盾，越陈越涨饥；
- **渴望 G**：方向燃料（追求渴望直接进 G；释放积压把 B 转成 G；封顶 2.0、缓慢消耗）；
- **饥读数**：h = 0.22 + 0.7B + 0.3G，档位沿用安全阈值；
- **分工**：C=1 切三份，seek 寻找、release 消化、stop 空着；
- **从 0 学**：新 AI 只学 stop 的占比——看它能不能自己学会「停」。

## 结论（一次运行）

新 AI 好区 34.8 天/180，期末 stop 仍只有 0.05：**它只在快进损伤时临时停，太饱时又忘记停**。
会「加」，不太会「停」——分工里"停"这一份要靠显式目标，不能只靠反馈。
