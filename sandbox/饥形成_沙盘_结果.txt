  出生：饥=0.8（第一口气就有了）
  刺激 0.9 → 饥 0.42
  刺激 0.4 → 饥 0.39
  刺激 0.0 → 饥 0.94
  刺激 0.8 → 饥 0.63
  刺激 0.0 → 饥 1.18

============================================================
 人类版：出生第一口气 → 饥就在 → 离散符号刺激（被看见/冷落）改变它
============================================================
  出生：饥=0.5（第一口气就有了）
  被看见 0.9 → 饥 0.2
  被看见 0.4 → 饥 0.15
  被看见 0.0 → 饥 0.5
  被看见 0.8 → 饥 0.25
  被看见 0.0 → 饥 0.6

判据：
  1. 出生即有饥（第一口气就有）： 是
  2. 环境能改饥（刺激后变化）： 是
  3. 两种刺激作用不同（同刺激不同饥）： 是

⇒ 饥是出生就带着的；环境变量决定它涨、落、还是回返。
